# Sub-project A — Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a launcher (`bin/phaverlite-ide`) that boots lem-ncurses with a project-local `config/init.lisp`, while writing nothing to the user's `$HOME`.

**Architecture:** A zsh launcher sets `LEM_HOME` and `XDG_*_HOME` env vars to in-repo paths under `var/`, then `exec`s `qlot exec sbcl --no-userinit --no-sysinit --load config/init.lisp`. Common Lisp deps (including lem itself, pinned to a verified SHA) are managed by qlot in `<repo>/.qlot/`. A second script, `bin/verify-isolation`, snapshots `$HOME` state before and after a launch to confirm zero leakage.

**Tech Stack:** zsh, qlot (Roswell-installed), SBCL, lem-ncurses, ASDF/Quicklisp.

**Spec:** `docs/superpowers/specs/2026-05-07-bootstrap-sub-project-a-design.md`

**Working directory for all commands:** the repo root, `<repo-root>`. (Engineer should `cd` there once at the start; subsequent paths in this plan are repo-relative unless prefixed with `/`.)

**Privacy reminder:** This is a public GitHub repo. Per `CLAUDE.md`:
- Never write `/Users/...` or `/home/...` paths into tracked files. Use `$HOME`, `~`, or repo-relative paths.
- Local git identity in this repo is set to the GitHub noreply email; do not change it.

## Task 3: Write `config/init.lisp`

**Files:**
- Create: `config/init.lisp`

- [ ] **Step 1: Create the config dir and init file**

Create `config/init.lisp` with exactly this content:

```lisp
;;;; config/init.lisp — PHAVerLite IDE bootstrap, sub-project A.
;;;; Loaded by bin/phaverlite-ide via `sbcl --no-userinit --no-sysinit --load`.
;;;; Job: prove the launcher boots lem-ncurses with our config and nothing else.

(in-package #:cl-user)

;; Tell CFFI where to find native libs we built ourselves (see bin/build-deps).
;; Must happen BEFORE (ql:quickload :lem-ncurses) — async-process loads its
;; .dylib at compile time, so the search path needs to be set first.
;; The PHAVERLITE_IDE_LIB env var is set by bin/phaverlite-ide; we read it
;; rather than hardcoding the repo path so this file stays portable.
(ql:quickload :cffi :silent t)
(let ((libdir (uiop:getenv "PHAVERLITE_IDE_LIB")))
  (when (and libdir (not (zerop (length libdir))))
    (pushnew (uiop:ensure-directory-pathname libdir)
             cffi:*foreign-library-directories*
             :test #'equal)))

(ql:quickload :lem-ncurses :silent t)

;; Verification banner — appears in *Messages* so we can confirm THIS init.lisp
;; ran (vs. some stray ~/.config/lem/init.lisp). Used by bin/verify-isolation.
(defparameter *phaverlite-ide-banner*
  "[phaverlite-ide] sub-project A bootstrap loaded")

;; Defer the message until lem is up, then start the editor.
(lem:add-hook lem:*after-init-hook*
              (lambda () (lem:message *phaverlite-ide-banner*)))

(lem:lem)
```

- [ ] **Step 2: Sanity-check with sbcl directly (no launcher yet)**

This step verifies the file parses and CFFI/quickload work. We do NOT call `(lem:lem)` here (would take over the terminal); instead, load only the part before `(lem:lem)`.

Run:
```bash
PHAVERLITE_IDE_LIB="$PWD/var/lib" qlot exec sbcl --no-userinit --no-sysinit \
  --eval '(ql:quickload :cffi :silent t)' \
  --eval "(let ((libdir (uiop:getenv \"PHAVERLITE_IDE_LIB\"))) (when libdir (pushnew (uiop:ensure-directory-pathname libdir) cffi:*foreign-library-directories* :test #'equal)))" \
```

Expected: `[init-parse-ok] lem-ncurses loaded, lem:lem fbound: T`. If you see a CFFI dlopen error for `libasyncprocess.dylib`, you forgot to run `bin/build-deps` after `qlot install` — go run it.

## Task 4: Write `bin/phaverlite-ide` launcher

**Files:**
- Create: `bin/phaverlite-ide`

- [ ] **Step 1: Create the launcher**

Create `bin/phaverlite-ide` with exactly this content:

```zsh
#!/usr/bin/env zsh
# bin/phaverlite-ide — launch lem-ncurses with project-local config.
#
# Sub-project A: env-isolated bootstrap. No $HOME writes; no SBCL user/system
# init; no lem fallback to ~/.lem or ~/.config/lem.

set -euo pipefail

# Resolve repo root from this script's location (no hardcoded paths).
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
REPO="$(cd "$SCRIPT_DIR/.." && pwd)"

# Friendly precondition checks.
if ! command -v qlot >/dev/null 2>&1; then
  print -u2 "phaverlite-ide: 'qlot' not found on PATH."
  print -u2 "Install via Roswell: ros install fukamachi/qlot"
  exit 1
fi
if [[ ! -d "$REPO/.qlot" ]]; then
  print -u2 "phaverlite-ide: $REPO/.qlot/ missing. Run 'qlot install' first."
  exit 1
fi
if [[ ! -f "$REPO/var/lib/libasyncprocess.dylib" ]]; then
  print -u2 "phaverlite-ide: $REPO/var/lib/libasyncprocess.dylib missing."
  print -u2 "                Run 'bin/build-deps' after 'qlot install'."
  exit 1
fi
if [[ ! -f "$REPO/config/init.lisp" ]]; then
  print -u2 "phaverlite-ide: $REPO/config/init.lisp missing."
  exit 1
fi

# Env isolation: every per-user state path lives inside the repo.
mkdir -p \
  "$REPO/var/lem" \
  "$REPO/var/xdg-config" \
  "$REPO/var/xdg-data" \
  "$REPO/var/xdg-cache"

export LEM_HOME="$REPO/var/lem"
export XDG_CONFIG_HOME="$REPO/var/xdg-config"
export XDG_DATA_HOME="$REPO/var/xdg-data"
export XDG_CACHE_HOME="$REPO/var/xdg-cache"

# Where config/init.lisp finds our hand-built native libs (libasyncprocess).
export PHAVERLITE_IDE_LIB="$REPO/var/lib"

# HOME is intentionally NOT remapped (would break ssh, git, terminal).

cd "$REPO"
exec qlot exec sbcl \
  --no-userinit \
  --no-sysinit \
  --load "config/init.lisp"
```

## Task 5: Write `bin/verify-isolation` and run the full DoD check

**Files:**
- Create: `bin/verify-isolation`

- [ ] **Step 1: Create the verification script**

Create `bin/verify-isolation` with exactly this content:

```zsh
#!/usr/bin/env zsh
# bin/verify-isolation — manual DoD check for sub-project A.
#
# Snapshots the set of files/mtimes under $HOME paths that lem/sbcl/qlot
# might write to, then launches bin/phaverlite-ide. After lem exits,
# diffs the snapshot to report any new or modified files.
#
# Pass: zero new files, zero mtime changes.
# Fail: any file under the watched paths was created or modified.

set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
REPO="$(cd "$SCRIPT_DIR/.." && pwd)"

# Paths we promise NOT to write to.
WATCH=(
  "$HOME/.config/lem"
  "$HOME/.cache/lem"
  "$HOME/.lem"
  "$HOME/.qlot"
  "$HOME/.sbclrc"
)

snapshot() {
  local out=$1
  : > "$out"
  for p in $WATCH; do
    if [[ -e "$p" ]]; then
      # mtime in epoch seconds + path; one line per file.
      find "$p" -type f -exec stat -f '%m %N' {} + >> "$out" 2>/dev/null || true
    fi
  done
  sort -o "$out" "$out"
}

BEFORE="$(mktemp -t phaverlite-iso-before)"
AFTER="$(mktemp -t phaverlite-iso-after)"
trap 'rm -f "$BEFORE" "$AFTER"' EXIT

print "[verify-isolation] snapshotting \$HOME state..."
snapshot "$BEFORE"
print "[verify-isolation] launching bin/phaverlite-ide. Exit lem normally to continue."
print ""

"$REPO/bin/phaverlite-ide"

print ""
print "[verify-isolation] re-snapshotting..."
snapshot "$AFTER"

if diff -u "$BEFORE" "$AFTER" > /dev/null; then
  print "[verify-isolation] PASS: no changes under watched paths."
  exit 0
else
  print "[verify-isolation] FAIL: changes detected:"
  diff -u "$BEFORE" "$AFTER" | sed 's/^/  /'
  exit 1
fi
```

- [ ] **Step 2: Make it executable**

Run:
```bash
chmod +x bin/verify-isolation
```

- [ ] **Step 3: Run the full DoD check**

Run:
```bash

```
Expected flow:
1. Prints `snapshotting $HOME state...`
2. Launches lem-ncurses; you see the banner in `*Messages*`.
3. You exit lem with `C-x C-c`.
4. Prints `re-snapshotting...`
5. Prints `[verify-isolation] PASS: no changes under watched paths.` and exits 0.

If FAIL: the diff output names the offending paths. Common culprits:
- A library writing to `~/.config/<name>/` even though `XDG_CONFIG_HOME` is set — investigate which env var that lib honors and add it to the launcher.
- Lem writing a recent-files list to `~/.lem/` — confirm `LEM_HOME` is being read by this lem version (search `.qlot/dists/lem/software/lem-*/` for `LEM_HOME`).

Fix the launcher, re-run until PASS.
